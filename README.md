# Simple Resume Website

A clean and responsive single-page resume website built using **HTML5 and CSS3**. This project presents personal information, education, technical skills, experience, projects, and contact details in a professional and easy-to-scan layout.

## 📌 Project Overview

The **Simple Resume Website** was developed to practice:

* Semantic HTML5
* CSS3 styling
* Responsive web design
* CSS Flexbox
* CSS Grid
* Organizing structured information
* Creating professional web layouts

## ✨ Features

* 👤 Profile section
* 🎓 Education section
* 💻 Technical skills section
* 💼 Experience section
* 🚀 Projects section
* 📧 Contact information
* 📱 Responsive design
* 🎨 Clean and professional UI
* 📐 CSS Grid and Flexbox layouts

## 🛠️ Technologies Used

* **HTML5**

## 🖥️ Sections

### Profile

Contains a short professional introduction.

### Education

Displays academic qualifications and college information.

### Skills

Shows technical skills using responsive skill tags.

### Experience

Displays internship or professional experience.

### Projects

Highlights completed projects with their technologies.

### Contact

Provides email, GitHub, LinkedIn, and location details.

## 📱 Responsive Design

The website is designed to work across:

* 💻 Desktop
* 💻 Laptop
* 📱 Mobile
* 📟 Tablet

CSS media queries are used to adjust the layout for smaller screen sizes.
